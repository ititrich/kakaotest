'OVERPASS' 패치 후속 대응 가이드 잇따라 발표 — "인터넷 노출 시스템부터 즉시 패치"

9월 8일 공개된 SAP 커널 취약점 'OVERPASS'(CVE-2026-44756, CVSS 10.0)에 대응해 SAP가 배포한 보안 노트 3747649(ABAP·Java 커널 및 SAP Web Dispatcher 대상)를 둘러싼 후속 대응 가이드가 보안 업계에서 잇따라 나오고 있다. OVERPASS는 인증 이전 단계에서 처리되는 공유 커널 코드에 위치해 인터넷 노출 웹 계층, 모든 사용자가 접속하는 SAP GUI 계층, SAP 시스템 간 연결에 쓰이는 RFC 계층에서 모두 도달 가능하다는 점이 지적됐다. 현재까지 확인된 실제 악용 사례나 공개된 개념증명(PoC) 코드는 없지만, SAP 전체 랜드스케이프를 점검해 인터넷에 노출된 시스템부터 우선적으로 커널 패치를 적용할 것이 권고된다.
