오늘의 요약. SAP가 9월 10일 서비스·지원 포트폴리오의 실질적 성과를 공개했다. 파운데이셔널·어드밴스드·맥스 3단계 성공 플랜과 통합 서비스 릴리스 모델을 통해 고객이 AI를 핵심 업무에 내재화하도록 돕는다는 내용이다. 보안 측면에서는 9월 8일 패치데이에서 공개된 CVSS 10.0 등급의 SAP 커널 취약점 'OVERPASS'(CVE-2026-44756)에 대한 긴급 패치 적용이 여전히 최우선 과제로, 인증 이전 단계에서 트리거되는 특성상 인터넷에 노출된 다수의 SAP 시스템이 위험에 노출된 것으로 알려졌다. 규제 측면에서는 지난 7월 확정된 EU와의 10년 구속력 있는 유지보수 정책 시정 약속의 이행 상황이 계속 주시되고 있다. AI 영역에서는 정형 데이터 특화 모델 SAP-RPT-1.6과 Joule 조달 에이전트 2차 웨이브가 9월 일반 공급에 들어가며 SAP Business AI 포트폴리오 확장이 이어지고 있다.

9월 보안 패치데이 — CVSS 10.0 'OVERPASS' 커널 취약점 등 치명적 결함 다수 패치

SAP가 9월 8일 정기 보안 패치데이에서 신규 보안 노트 19건과 기존 노트 업데이트 1건을 발표했다. 이 중 SAP 커널의 Extended Passport Processing(EPP)에서 발견된 메모리 손상 취약점 'OVERPASS'(CVE-2026-44756, CVSS 10.0)는 세션 인증 이전 단계에서 처리되는 EPP의 특성상 사용자 잠금·역할·권한객체 등 표준 보안 통제를 우회해 인증 없이 원격 코드 실행이 가능하며, 인터넷에 노출된 SAP 시스템 1만여 대가 영향권에 있는 것으로 파악됐다. 이 외에도 NetWeaver Message Server의 인증 누락 취약점(CVE-2026-58240, CVSS 9.8), SAP Cloud Application Programming Model 라이브러리의 자격증명 노출 취약점(CVE-2026-76969, CVSS 9.4), SAP GUI for Java의 접근통제 결함(CVE-2026-66768) 등 치명적 등급 취약점이 포함됐다. Security Note 3747649로 커널 패치가 제공되므로 관련 시스템 운영 기업은 즉시 적용이 권고된다.
